# Cloudflare setup

This project is designed to be connected to a GitHub repository and automatically built from the `main` branch.

Use these build settings when Cloudflare asks for them:

```text
Production branch: main
Build command: npm run build
Output directory: _site
```

The important part is that Cloudflare runs Eleventy and publishes the generated `_site` directory.

## If Cloudflare asks for a deploy command

For a static-assets Worker workflow, use the command/configuration generated by Cloudflare's current interface. The project itself does not need a manual deployment command: its source files and build output are already configured for this workflow.

## Publishing

Once GitHub and Cloudflare are connected:

```powershell
git add .
git commit -m "Add new science article"
git push
```

Cloudflare should rebuild from the new `main` commit.
